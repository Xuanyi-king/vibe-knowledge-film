# 《抢先一步》36 秒分镜

一句话论点：更短的路不一定更快；摆线起步更陡，先降下更多高度，较早获得速度，抵消多走的路。

概念与形象：①路程与时间不同——两条实体滑轨与两枚珠子（质点的放大示意），常见的滑梯、竞速；②高度转速度——珠子的垂直落差与带单位速度尺，难点是同一时刻不是同一高度；③最速曲线——先看获胜，再命名摆线；两轨比赛展示结果，最优性引用数学结论而非宣称凭两轨证明。

三种开场：直接比赛（推荐，先亲眼看结果）；先选轨道再揭晓；先量长度再放珠子。采用直接比赛。
世界 C 夜曲。一个实验台、同一空间尺度。蓝=直线，金=摆线；白=共同条件。轨道、起终点、计时器在结尾回场。珠子不旋转，避免滚动球模型混淆。

# 事实表与计算

输入条件（任务规定）：端点水平相距1m，落差0.6m；g=9.81m/s²；无摩擦质点，静止释放，匀强重力。无滚动转动能。

| 事实 | 出处/推导 | 把握 |
|---|---|---|
| 静止释放质点的最速降线为一段摆线 | Eric W. Weisstein, “Brachistochrone Problem”, MathWorld, https://mathworld.wolfram.com/BrachistochroneProblem.html | 高 |
| 摆线参数式x=a(θ−sinθ), y=a(1−cosθ)，y向下 | MathWorld “Cycloid”, https://mathworld.wolfram.com/Cycloid.html；坐标方向按本片调整 | 高 |
| 速度v=√(2gy) | 机械能守恒mgy=mv²/2；上述无摩擦、静止条件 | 高 |
| θ终=3.2339751452171397，a=0.3006410009354001m | 求(θ−sinθ)/(1−cosθ)=1/0.6，再a=0.6/(1−cosθ)，scipy brentq | 数值计算 |
| 摆线时间0.5661431779960597s | t=√(a/g)θ；弧长微元除速度积分所得 | 数值计算 |
| 直线时间0.6797892979713829s | L=√(1²+0.6²)，沿轨加速度g·0.6/L，t=√(2L²/(g·0.6)) | 数值计算 |
| 长度：直线1.1661903789690602m，摆线1.2580921822198052m | L直=√1.36；L摆=4a[1−cos(θ终/2)] | 数值计算 |
| 0.250s时：直线落差0.0811488971m，v=1.2618008402m/s；摆线落差0.2578780426m，v=2.2493481712m/s | 直线y=0.6(t/t直)²；摆线θ=t√(g/a)；v=√(2gy) | 数值计算 |
| 摆线起步更陡使它较早获得速度 | 上述运动学和能量公式；这是直觉解释，影片没有提供变分法最优性证明 | 高，说明范围 |

来源以提供的本地缓存查阅，未调用外部模型。屏幕保留3位小数，到达用实际未舍入值判断。首赛和复赛均为统一6倍慢放；原因段为12倍慢放，0.250s时暂停，随后可见回放复位。球形标记仅表示位置，不是有半径、有转动惯量的滚动小球。轨道厚度和装置底座为示意。

# PR #1 第二轮修订与验收

范围：在原分支完善，不重复仓库调研、不重做两部36秒影片。历史简报不一致的案例不能证明Skill提升模型能力；本轮也没有真实目标模型结果。

## 实际增强

- 可选Three.js层：固定版本与SHA256的约720KB模块，离线运行；复用深度、PBR、环境反射、阴影、杆件与旋转体几何。已有Canvas工作流不变。[六秒镜头](../examples/governor_scene/README.md)包含23网格机构、无受光消融、动作条和编码抽帧，验证的是执行能力而非模型效果。
- `render.py --resume <seconds> [--jobs N]`：正式持久分段、源码/所有输入扩展名/运行时/编码参数身份、校验后复用、坏段重绘、内核锁、中断恢复、按绝对帧顺序合片。输出临时文件验证后替换。素材必须在本地非生成目录，不接受外部URL/符号链接/生成目录素材；不能缓存未追踪输入。
- `audio.py`：临时合音后检查音视频流、时长和全解码再替换final.mp4；编码失败或“退出成功但损坏”均保留旧片，有真实子进程负例测试。
- [中性单镜头目标模型探针](model-probe.md)：相同用户提示、公共API、参数与输出预算，只有Skill指导不同；默认不发请求。未配置目标提供商凭据，只有离线和本地假HTTP服务的程序测试，没有真实模型成绩。

## 统一视听制作增量

本轮进一步融合[九个项目的实际实现方法](capability-integration.md)，不是九套Skill叠加。公共`vk-motion.mjs`提供绝对关键帧、欠/临界/过阻尼解析响应、接触/回弹、Bezier路径、机位与tempo map；VK_SCORE把对象/材质/速度/动作/镜头/音乐/SFX共置同一时间源。`score_audio.py`提供原创材质激励、摩擦、气流、拨弦与用户授权采样、三个总线、自动化/滤波/短混响；采样来源显式登记。`analyze_music.py`只给onset/BPM/能量候选，不虚构downbeat或乐句。

[8秒原创《一击之后》](../examples/resonance/README.md)复用这些公共组件。关键帧返工解决支架压字、图形叠压、接触间隙与零接触速度、平面材质和手柄穿杆；没有复制参考片具体道具或重做长片。声音无需另抄时间常量。最终AAC与源混音按事件窗口回测，视觉接触另由实际帧和浏览器几何测试检查，二者不混为审美评分。

独立代码审查发现并实际复现：score额外BGM使同步参考缺轨、sample忽略声像、外层电影和内层score时间不一致仍通过。已补负例并修复；score的用户音乐进入sample/music总线，旧`--bgm`行为保留。**完整听音尚未验收**，没有音频播放能力；媒体和同步检测不代替主观质量。未实现完整物理求解、自动downbeat/乐句、专业DAW或通用资产加载器。

## 验证

Linux + Chromium154 + SwiftShader WebGL2，字体和可选运行时在本地安装。完整命令：

```bash
VK_BROWSER=/usr/bin/chromium python -m unittest discover -s tests -v
```

**42项通过**（最终45.707秒），日志见[evidence/revision/tests.log](../evidence/revision/tests.log)。包括持久缓存中断/续跑、MD素材与尺寸/浏览器参数变更、损坏片段、并行拼接顺序与中断取消排队分段、合片失败、源码编辑竞态、锁释放；音频失败/损坏保护；WebGL同刻乱序回放像素和杆长约束；不联网准备/两次假HTTP调用。

独立代码审查发现Markdown扩展名被错误排除：实际改labels.md后仍复用旧段（重绘0而非3）。已移除扩展名排除，所有真实输入文件保守哈希；生成目录素材在页面初始化与逐帧时拒绝读取。该负例复现后修复，完整测试通过。没有为解决该问题重做长片。

六秒影片180帧、1920×1080、30fps、H.264/yuv420p、AAC48kHz，全解码无错误/无黑段候选；[媒体报告](../evidence/governor_scene/media.json)。实际看过PBR/无受光同刻图、0–6秒动作条与编码拼图；未进行完整主观听音。

初次集成warm恢复4.923秒，3段全部复用、raw哈希不变；之后收紧输入追踪使该历史缓存失效，当前行为以自动化测试为准。没有单独冷渲染计时，不报虚构加速比。

这收敛的是当前树和PR最终差异，**没有强推改写Git历史**；历史大对象仍存在。只需要当前版本时可用`git clone --depth 1 --branch feat/director-evidence-workflow ...`，不把工作树缩减宣传成完整历史已瘦身。

八秒最终媒体为240帧1080p30、H.264/AAC48kHz、全解码通过；8个声音事件与最终AAC解码窗口的相关度最低0.99749，测得编码延迟均0样本，声明时间恰落30fps帧网格。响度实测-20.02 LUFS、真实峰值-4.07 dBTP；这是测量，不是音色或电影感评分。5.719–6.167秒静音候选对应有意停顿与下一音符尚未进入，7.646秒后的低能量尾部为收尾。

八秒片warm恢复9.582秒，4段全复用、raw哈希不变。冷导出约292.364秒（两核CPU、SwiftShader，期间并行测试），不将其当跨平台性能保证。制作过程中一次主动中断、一次文档编辑触发保守失效后重算，没有绕过身份检查或发布未验证拼接片。

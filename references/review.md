# 看图，判断原因，局部返工

技术检查不能判断电影感。审查者先声明实际看到了什么：源码、静帧、Motion Strip、视频、音频各分开。
不能播放视频时，时间采样只能支持采样点和中间态判断，不能宣称完整观看。

## 一轮审查只处理最重要的三个问题

```text
镜头 ID / 时间点：
证据文件与可见事实（不写“低级”“高级”）：
观众可能误解或看不清什么：
根因假设：
返工层级：实现 / 运动 / 构图 / 镜头设计 / 概念 / 剧本
最小修改与预期可见结果：
同刻修改前 / 后：
结果：保留 / 撤销 / 仍未解决；其他镜头是否受影响：
```

| 可见问题 | 优先返工层级 | 先尝试 |
|---|---|---|
| 对象只有标签才能辨认 | 概念 / 形态 | 换锚点、轮廓、尺度参照；不先加光 |
| 观众不知道看哪里 | 构图 | 主体放大，压低辅助对比，简化同时变化 |
| 精致但只是装饰 | 镜头设计 | 写出该动作证明什么；无答案就删 |
| 对象漂浮、像贴纸 | 实现 / 空间 | 接触点、遮挡、统一光源和阴影 |
| 动作匀速或急停不自然 | 运动 | 查速度曲线、接触前后帧；物理运动不要随意缓动 |
| 转场中对象身份丢失 | 镜头设计 | 留锚点、同方向接续；必要时明确剪切 |
| 三个镜头都像 PPT | 镜头设计 | 改观看尺度和揭示顺序；避免每镜标题+卡片+总结 |
| 很美但讲不清 | 概念 / 剧本 | 补可见的中介原因，或换视觉隐喻 |

## 客观检查的边界

`render.py --det`：同环境乱序帧相同，不证明跨 OS/字体版本逐像素一致。
`check_media.py`：规格、编码、时长、解码、音轨峰值、黑段/静音/跳变候选；有意黑场和停顿需要人工判读。
字体加载由页面/渲染器报告。字幕需用真实字体 `fr.measure`，不是字符数估计。
画面越界/字幕遮挡/错误事实/分镜不一致：对照当前镜头契约、截图和计算测试人工复核，不能凭视频亮度自动断言。
报告不得把“未检测”写成“通过”。

## 截图与动态证据

每镜至少留落定帧；重要动作抽起点/准备/接触前/接触/余动/落点。转场用 --motion，怀疑速度问题渲 2–4 秒 clip。
重新截**同样时刻**，避免用不同时刻制造提升。保留首版文件再覆盖当前结果。
问题反复出现时重新审视概念，不用固定轮数代替判断；已解决时停止。最终重渲受影响片段、再出全片及编码报告。

## 对照实验

相同题目、模型版本、提示输入、资源、时长、推理/渲染预算；两组独立上下文，原版先冻结。
保留具体模型 ID（不可得写 unknown）、调用数/token（不可得写 unavailable）、命令耗时、轮次、原始产物和审查者身份。
审查比较创意、清晰度、镜头完成度、自然度、统一性、错误、返工成本；使用具体画面事实，不虚构打分。
自评与盲评分开；单样本是案例，不能证明 DeepSeek 或所有主题都提升。环境没 API 时可以做同会话模型样片，但标出适用范围。

## 声音与动作一起审

共享事件工程先读[choreography](choreography.md)。每个关键接触取前/当刻/后至少三帧：核对到达速度、间隙、形变/余振与稳定时刻，再独听sfx、music及最终MP4。相机运动是否隐藏了因果，声音是否抢了阅读任务，停顿是否有意图，需要真实看/听。

关键动作再执行[action-checks](action-checks.md)的实际帧条件，绑定当前媒体与事件指纹。`check_av.py`的延迟/相关度只证明编码混音与源参考的时间关系，不证明画面对象确实发生接触，也不是音色评分。无法播放时写“主观听音未验收”，保留独听轨供人工评审；不能因技术绿色把这一项勾完。起音、峰值、尾音分开记录，不给所有声效套相同毫秒偏移。

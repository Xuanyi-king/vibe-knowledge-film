# 看图，判断原因，局部返工

技术检查不能判断电影感。审查者先声明实际看到了什么：源码、静帧、Motion Strip、视频、音频各分开。
不能播放视频时，时间采样只能支持采样点和中间态判断，不能宣称完整观看。

先按观众做三遍：遮字幕看对象与原因；独立读完整字幕看通顺和递进；先听仅Music，再听加入SFX/Ambience后的成片。拿实际参考片的同类景别对照暗部、字、材质、主体大小与留白，不只查规格是否合格。分镜没有兑现或文案仍难懂，要回到讲解设计。

## 优先处理影响最大的实际问题（不要求问题数或返工轮数）

只记录影响理解或观感的实际问题，集中处理优先项；复查修改区间和接缝，未变化的有效证据与渲染段直接复用。问题解决就停止，不为轮数、评分或没有画面证据的“再高级一点”重复全片返工。下面格式用于已有审片记录，不另建报告。

```text
镜头 ID / 时间点：
证据文件与可见事实（不写“低级”“高级”）：
观众可能误解或看不清什么：
根因假设：
返工层级：实现 / 运动 / 构图 / 镜头设计 / 概念 / 剧本
最小修改与预期可见结果：
同刻修改前 / 后：
结果：保留 / 撤销 / 仍未解决；其他镜头是否受影响：
```

| 可见问题 | 优先返工层级 | 先尝试 |
|---|---|---|
| 对象只有标签才能辨认 | 概念 / 形态 | 换锚点、轮廓、尺度参照；不先加光 |
| 观众不知道看哪里 | 构图 | 主体放大，压低辅助对比，简化同时变化 |
| 精致但只是装饰 | 镜头设计 | 写出该动作证明什么；无答案就删 |
| 对象漂浮、像贴纸 | 实现 / 空间 | 接触点、遮挡、统一光源和阴影 |
| 动作匀速或急停不自然 | 运动 | 查速度曲线、接触前后帧；物理运动不要随意缓动 |
| 转场中对象身份丢失 | 镜头设计 | 留锚点、同方向接续；必要时明确剪切 |
| 三个镜头都像 PPT | 镜头设计 | 改观看尺度和揭示顺序；避免每镜标题+卡片+总结 |
| 记住术语却说不清为什么 | 概念 / 剧本 | 找出跳过的推理，补可见的中间原因；必要时换对象 |
| 看懂知识却说不出收获 | 剧本 / 结尾 | 回到前文依据，用合适镜头与直白字幕点明新认识及边界，不硬加处方 |

## 客观检查的边界

`render.py --det`：同环境乱序帧相同，不证明跨 OS/字体版本逐像素一致。
`check_media.py`：规格、编码、时长、解码、音轨峰值、黑段/静音/跳变候选；有意黑场和停顿需要人工判读。
字体加载由页面/渲染器报告。字幕需用真实字体 `fr.measure`，不是字符数估计。
画面越界/字幕遮挡/错误事实/分镜不一致：对照当前镜头契约、截图和计算测试人工复核，不能凭视频亮度自动断言。
报告不得把“未检测”写成“通过”。帧差、亮度、运动覆盖率只提示复看位置：缩略图均值不能证明没有机位变化，图像相似度不是相同像素百分比，字幕带变化间隔不等于句子停留时长。不能由两条参考片推出通用注意力周期或最佳切镜配额。

## 截图与动态证据

手机观看是默认验收环境之一：[mobile](mobile.md)。从最终MP4看390/320px原尺寸图，以及压力副本的同刻图；至少含动作中间态和字幕完整停留帧。必要数值/单位读不清就是返工原因，不因桌面截图精致而放行。先区分原始设计、母版编码与压力转码损失，再改信息密度、标注或局部照明，不一律放大全字或抬曝光。移动报告仅提供风险/证据，未登记文字、遮挡、主体辨认、舒适度仍需真实看图；实际抖音未上传即未验证。

前期集中预览复用试画阶段同一段完整关键推理及其落定后的停留，不另开预览轮次；最终仍审查当前完整编码，旧证据仅在对应输入与输出未变时复用。核对每步新字幕有没有对应的可见依据，区分对象运动、摄影机运动、字的变化；不能用更多漂浮或切镜代替解释。结尾同时检查：画面演出的改变是什么、观众能用自己的话说出什么具体收获，以及建议是否越过证据。

按风险保留代表性落定帧，重要动作取能判断起态、中间态与结果的证据；接触动作检查前/当刻/后。转场用 --motion，怀疑速度问题渲 2–4 秒 clip。
重新截**同样时刻**，避免用不同时刻制造提升。保留首版文件再覆盖当前结果。
问题反复出现时重新审视概念，不用固定轮数代替判断；已解决时停止。最终只重渲受影响片段，复用未变段落，再合成全片并做必要编码检查。

## 声音与动作一起审

共享事件工程先读[choreography](choreography.md)。每个关键接触取前/当刻/后至少三帧：核对到达速度、间隙、形变/余振与稳定时刻，再独听sfx、music及最终MP4。相机运动是否隐藏了因果，声音是否抢了阅读任务，停顿是否有意图，需要真实看/听。

关键动作再执行[action-checks](action-checks.md)的实际帧条件，绑定当前媒体与事件指纹。`check_av.py`的延迟/相关度只证明编码混音与源参考的时间关系，不证明画面对象确实发生接触，也不是音色评分。无法播放时写“主观听音未验收”，保留独听轨供人工评审；不能因技术绿色把这一项勾完。起音、峰值、尾音分开记录，不给所有声效套相同毫秒偏移。

如果加入拟音后音乐被频繁压低、接触声过尖或同类声音重复，优先删减拟音与多余duck，而不是再加混音处理。动作有触感不等于每个动作都要发声。保留Music/SFX/Ambience接口与分轨，不强迫所有轨道持续发声。

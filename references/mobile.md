# 横屏知识电影：手机上也要完成解释

仍以1920×1080、16:9、30fps制作母版。不默认裁成9:16，不让用户选择一串导出参数。把观看环境纳入分镜：哪些字必须读懂，哪些只是可以不读的细节？一个手机上看不清的公式没有完成讲解。

## 先减负，再重排

- 必要信息：当前动作、实验条件、核心数值与单位、字幕结论。它们必须能在320/390px预览中读出，不能靠观众暂停放大。
- 次要信息：出处、器具编号、装饰字。可降权，但不能把知识前提藏在小字里。文献可放事实表/结尾单独停留，不要求每镜堆出处。
- 文字过多先精简、分阶段揭示、改为动作、重构布局、增加停留；不优先缩字。移除重复的信息区，给真正需要的读数留位。
- 按对象关系设计标注。三个读不清的刻度可换成一条从真实支点延伸到施力点的距离带，而非把三个标签全部放大挤在一起。单位与数字一起设计。

画布字号不是手机字号：84px在320px宽显示时约14px **em**，并非实际字形墨迹高度。字重、宋体细笔画、字数/字距、对比、周围复杂度、显现过程与停留同样影响阅读。320/390是最小诊断场景，并非所有手机的播放器尺寸、DPR或平台实测；原尺寸查看预览，不能先放大截图再认领可读。

`check_mobile.py`以14px em提示主要字幕/标题/数字风险、12px提示必要标签、11px提示次要文字；是按角色的保守排查起点，不是统一最小字号标准，更不是舒适度通过证。短数字与复杂中文不能仅按同一em大小判断。

## 暗部与运动

先看原始母版缩图，再看压力副本，区分设计问题和编码损失。原始缩图就读不到的5px刻度，不能靠4K或高码率补救。

保留背景暗度，用近侧补光、物体转向、反射环境和材质差异恢复必要结构；不整幅抬亮、不依赖细金边或强锐化。重要线条需要在缩图仍有连续形状，而不是只在1920截图看见。主体的辨认不能依赖精细纹理；接触/位移的轮廓和支撑关系应在手机上存在。

选择接触前/当刻/后、运动中间态、字幕完整显现和落定停留帧。不能只检查最漂亮的一帧。运动中的模糊若隐藏知识因果，先修改运动/机位/显现时机，而非加字幕解释。

## 自动证据，导演判读

正式`produce.py`在媒体/同步之后调用：

```powershell
python scripts/check_mobile.py <project>/renders/final.mp4 --project <project> --output <project>/review/mobile
# 可选更强压力；不会覆盖母版，不是抖音官方配置
python scripts/check_mobile.py <project>/renders/final.mp4 --project <project> --profile 540p-crf33 --output <project>/review/mobile-strong
```

默认输出390/320px的原始与720p/CRF30压力副本截图/拼图及JSON。备选540p/CRF33；均为H.264 veryfast压力测试，保持比例/帧数/帧率/时长，原音频包复制并检查负载hash及音轨起止。它们不是建议上传的官方参数，也不证明真实抖音转码。压力副本单独保留；1080p CRF14母版保持不变，不默认强锐化或升4K。

未指定时间时从均匀样本、已声明动作条件与动作中间态选取；关键镜头可在源码声明`window.VK_MOBILE_TIMES=[...]`，或CLI传`--times`，不是向用户索取技术参数。最终像素来自MP4，浏览器只提供同一指纹下的布局与时间，不把浏览器静帧冒认为编码后画面。

`type`可声明`importance:'essential'|'supporting'|'decorative'`、稳定`id`。它记录真实字宽、字阶、当前变换后的框和em尺寸；每次seek重置，`VK_LAYOUT()`读出。无需复制一套字号/位置到QA文件。其框是保守排版区域，不是像素墨迹或遮挡检测。原Frame.text/VKit未登记的文字会明确留为未验证；旧作品无需为运行而迁移，不能据此宣称全部文字已扫描。

只有作者明确提供平坦`background`色时才计算声明颜色的相对亮度对比；未知/透明/渐变或实际三维背景仍需看图，不能用声明色比值当作像素实测。大小、越界、宽字距、主动文字blur仅报具体时间点候选，不给作品打清晰度或电影感分数。状态始终`needs_visual_review`，没有“手机自动通过”。

带project的检查会拒绝过期事件、母版或源码；报告绑定输入/事件/视频SHA。纯MP4模式也可用，但没有来源布局数据时必须写未验证。生成失败不覆盖旧证据/母版；正式生产遇到技术错误会恢复原成片。报告有风险时Agent应查看原尺寸图并局部返工，不能把exit 0当作阅读验收。

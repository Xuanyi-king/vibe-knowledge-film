# 复杂镜头：复用场景算法，自己决定表达

复杂并不自动需要3D。先写“必须看清的关系”，再选最小实现：

| 需要 | 继续 Canvas / VKit | 使用可选场景层 |
|---|---|---|
| 文字、图表、插画、少量投影 | 排版、Path2D、分层、手工明暗足够 | 不值得增加WebGL |
| 多物体交错、转动后遮挡改变 | 需要自己做面排序，复杂度快速上升 | 深度缓冲、层级变换、标准几何 |
| 形状随光源/视角改变受光 | 渐变和贴图是屏幕空间近似 | PBR粗糙度/金属度、环境反射、阴影贴图 |
| 多杆机构、旋转对称器物 | 不要让模型重写投影、法线、三角化 | `rod.between`、`lathe`与Three内置几何 |
| 有机生物形状、布料/流体、真实镜头光学 | 两者都没有现成通用解法 | 需要合法模型/专用求解器，不能凭球体拼接宣称已支持 |

本次实际验证的范围是**多部件刚性机构、遮挡、反射、接触阴影与相机**。未实现通用动力学、光线追踪、景深、运动模糊或任意GLTF导入。阴影是PCF贴图，不是面积光路径追踪。看图判断收益，不按技术名词判断。

## 轻量模型的制作顺序

1. **对象拆解。** 写5–8个语义部件及父子关系，明确固定件、运动件、关节。只建能解释机制的细节。
2. **选成熟几何。** 箱体/球/圆柱直接用Three；花瓶、轴套、镜筒用半径-高度profile→`lathe`；两点之间用`rod.between`。不要手写三角网格、投影、遮挡排序或反射算法。
3. **先验收无材质的姿态。** 在起/中/末三个时刻检查关节闭合、杆长、穿插。物体看不清先改轮廓/机位，不先堆材质。
4. **一次加一种表面。** 哑光物主要靠形体受光；金属需要环境反射，粗糙度控制高光宽度。保持一个主要光向，背景、阴影和物体亮度协调。
5. **相机最后动。** `pose(t)`只赋绝对值；相机与物体时间分开。重要的前后遮挡要抽中间帧；必要时停下来比较。

给执行模型的一轮输入只包含：当前部件表、姿态约束、这几个API与一个截图命令。复杂部件可单独生成并验收后再装配，不要求模型一次写整个世界。

## 最小接入

```bash
python engine/get_scene_assets.py
# 再正常使用 render.py 的 --stills / --det / --motion / --resume
```

该可选安装器下载固定Three.js 0.180.0的两个模块与MIT许可证，逐文件SHA256验证，约720KB JS，放在忽略的engine/vendor/。没有npm构建或渲染时CDN请求；Canvas旧工程无需安装。

在工程的异步初始化里（完整例子见[film.js](../examples/governor_scene/film.js)）：

```js
const {THREE:T, studio, rod, lathe} = await import('/engine/vk-scene.mjs');
const layer=studio({target:[0,1,0],position:[4,3,6]});
const steel=new T.MeshStandardMaterial({color:'#9cabb0',metalness:.88,roughness:.26});
const beam=rod(steel,.03); layer.scene.add(beam);
const vessel=lathe([[0,0],[.4,0],[.45,.1],[.3,.8],[0,.8]],steel);
layer.scene.add(vessel);
VK.film({dur:6,theme:'flat',bloom:0,grain:0,draw(fr,t){
  beam.between([0,2,0],[Math.sin(t),1,0]); // 每次赋绝对姿态
  fr.look.under=ctx=>layer.render(ctx);   // 3D先合成，文字仍由Canvas画
}});
```

初始化失败要设置`window.READY_ERROR`，不要留下永远等待的页面；示例已实现。渲染时WebGL上下文丢失会抛错，持久缓存只复用已验证片段。现代Chrome/Chromium需要WebGL2；无可用GPU时可试`VK_SOFTWARE_GL=1`，其余Canvas功能不受影响。软件GL更慢，不保证跨驱动像素相同。

## 一个真实短镜头

[离心调速器6秒源代码](../examples/governor_scene/)展示固定轴、旋转父节点、等长上下连杆、飞球和轴套。库负责深度、标准材质、阴影和相机；模型只需描述部件与姿态。
上铰点高度H、杆长L、张角θ：球的位置为`(±L sinθ, H−L cosθ, 0)`，轴套为`H−2L cosθ`，两根杆始终长L。所有运动从t重算；旋转角使用预定义角速度的解析积分，不逐帧积累。

这只是机构运动示意，**没有求解重力、惯性或负载下的平衡**；字幕明确标注。行程百分比按实际轴套位移归一化，不拿缓动进度冒充位移。
这套机制可迁移到连杆、分子键、支架与装配图；器物profile可迁移到瓶、透镜筒和机械壳体。不要把调速器当所有主题的固定模板。

实图、无光照消融与动作证据见[短镜头验证](../examples/governor_scene/README.md)。引入依赖的理由是解决可见的遮挡/受光问题，不能据此推断轻量模型创作能力已被证明提升。

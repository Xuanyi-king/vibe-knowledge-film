# 从概念到镜头

本页在叙事或镜头设计需要展开时读取。先看当前事实记录（可合并在 review/notes.md），不先找特效。以下卡片是可选工具，不要求全部填写。

## 候选方案卡（表达不确定时使用，无数量配额）

```text
观众卡点：为什么……？
可见命题：画面必须让人看到……导致……
表达机制：实物 / 最小实验 / 数量图 / 空间隐喻 / 文字 / 蒙太奇
画面方案：起始状态 → 唯一关键变化 → 结果
观众眼睛先看哪里，再看哪里：
比喻映射与失效边界：
惊喜和安静分别发生在哪一刻：
难点与最小验证：一个关键帧 + 一段 2–4 秒动作
```

比较时先排除错误和不可读，再比较解释力、记忆点、情绪、实现成本。没有必要给虚构精确分数。
直观但平淡：试改变观看尺度或揭示顺序。艺术性强但误导：补一个可见锚点或换方案。
只差颜色不算两个方案。例如“用下降轨道解释最速降线”与“把速度编码为纸带宽度”才是不同机制。

## 一页视觉方向

按作品需要记在 review/notes.md 或 direction.md：视觉概念一句；母题及回场方式；颜色与含义（含文字/背景）；标题/正文/数字的字体与字号；
构图和视线线路；光源与材质；摄影机与焦点；运动的快慢与停顿；声音和静音；明确不采用的装饰。
固定的是这些决定，不是所有镜头的版式。按实际风险用不同景别关键帧检验一致性，不用几十项主题配置。

## 认知镜头契约

用短卡或按叙事段落写，不必铺十列巨表。一个镜头可跨多句，安静的镜头也可承担思考与期待。

```text
S03 / 28–40秒
进入：观众以为……；此刻悬着的问题是……
事件：在保持……不变时，……发生，观众先猜/再看……
证据身份：亲身体验 / 实验重演 / 计算演示 / 理论示意 / 生活类比
离开：现在能依据……解释……；接下来会问……
制作：主体/形体与材质 → 前后景及负空间 → 起态/变化/落态/观察停留
机位：要看清的关系与移动理由；可不动
声音：音乐段落/留白/动作音锚点；不必卡每个字
交接：保留的对象/构图/声尾；若换模型或年代，用明确提示
字幕：在事件前提问、观察后命名；知识边界放进可读文字
```

**Shot Intent → Scene Objects → Spatial Composition → Animation States → Camera → Sound Events → Final Render。**
把事件锚点放在共享score，动作状态按绝对t计算；确定哪些状态可被VK_CHECKS从实际绘制对象读取。不要返回固定true或复制理想时间冒充动作验证。

- 亲身试验：刺激/暗示本身可能改变体验；它只建立好奇心，不直接证明论文。
- 实验重演：保留真实指令、组间差异与测量。动画秒数压缩注明，示例记录不画成实测频率。
- 计算：数字、图线与可见对象共读同一计算数据，不把数字缓动到预设答案当推导。
- 理论/隐喻：明确标出身份，保留映射与失效边界；不能因为它可视化就声称脑内过程被直接测得。

构图以观看任务定技术：Canvas适合图形/数学，SVG适合可控轮廓，3D解决真实深度/材质/遮挡。对象须可认，不要求写实；角色的形象、比例和动作状态应贯穿镜头。图像用`vk-image.mjs/paintImage(ctx,image,[x,y,w,h],{fit:"cover"})`保比例裁切，或contain留边；不要直接drawImage拉伸人脸。镜像实验只翻转同一像素源，比较时锁住缩放/光线/表情；“更瘦”的错误拉伸会直接污染解释。镜头移动回答“在哪里/谁与谁有关/什么改变”，没有目的就停住。

## 从生活疑问到新理解

先确定“观众起初怎样解释，最终凭什么换解释”。表达不确定时比较悬念、可见证据、惊喜、边界、情绪和制作风险；不要先选画风再往里塞研究。
真实人物/年份成为解决同一问题的行动者，不是文献目录。每次知识揭晓前让观众有预测或观察机会，揭晓后留消化时间。
结尾的回场须产生新的解释：同一道具还在，但观众不再以相同方式判断它。也可以回到日常选择而不重复片头道具；不能为了“温暖”推出未经检验的治疗建议。

**三次否决**：隐喻代替实证→补真实比较；研究只是题名贴纸→让方法/结果成为事件；片尾只有鸡汤→回到论证实际改变的判断。
参考[两题故事候选](story-cases.md)，不复制它们的道具或结构；面对新题材重新找自然剧情。

## 小模型执行包

每次只交给实现者：当前镜头契约、direction 的相关决定、需要的 API、前后交接状态、一个渲染命令。
这是内部注意力分配：当前子任务输出该镜头函数与自检记录，然后Agent自动推进下一镜，不结束整部制作。返工时提供实际截图和优先三个问题；要求给出原因及最小修改，避免全片重写。
复杂计算先独立运行并固定数据；布局先定画面坐标；动作最后添加。不要让模型同时猜事实、写剧本、画物体、调时序。
可迁移机制确有复用价值时再整理为参考；不要求每次作品修改 Skill。

## 《折叠》的可迁移经验

已看 `fold_old_vs_new.jpg`、fold_C 源码与实际渲染，不能把它归因于“加了 3D”：

1. 旧主体小而缺少参照：改版从血液尺度进入，告诉观众分子在哪。迁移：先定场，再揭局部。
2. 第六颗变色本身不是原因：改版让表面黏点与另一分子的凹口接触。迁移：画中介机制，补齐因果箭头。
3. 珠子到长杆再到细胞：层级变化保留对象身份。迁移：用同一锚点桥接尺度，而非任意缩放。
4. 第三镜先给结果，第八镜补原因：复用画面变成叙事收益。迁移：先悬念、后解释，再回看。
5. 光泽、暗窝、遮挡提升分组和可识别性；底层实心物体避免过曝。迁移：材质服务结构。

边界：这仍是压缩比例的教学示意，不能当真实分子动力学。原描述中单链“抓氧”是简化；
实际血红蛋白是四聚体、氧结合到血红素。不能把示意外形当结构证据。
也不能由这个案例推出“所有抽象图形都不好”。概率分布、相位、逻辑关系本来就可由图形准确表达。

# 曜石鎏金：用光组织一次知识发现

优先评估的成熟方向，**不是默认黑底皮肤**。深邃、温暖、典雅来自主体、光、材质、文字、动作与声音的共同取舍。金色只表达少量重要发现，不能替代知识事件。

## 先决定用到哪里

| 决定 | 适用判断 | 保持辨识度的方法 |
|---|---|---|
| 贯穿暗金 | 暗环境有助观察器具、几何、尺度或历史物件；材质确实参与理解 | 稳定的暖主光/干净暗部、克制金色发现、清楚的字幕与停顿 |
| 只做母题 | 生活、心理、自然主题需要真实明亮场景 | 章节/结尾可回用一个形状、字阶或暖色语义；实际场景不强行压黑 |
| 不采用暗金 | 颜色本身是证据、明场实验、档案忠实呈现、儿童/轻快主题不相配 | 保留视觉主次、字体比例、观看任务、自然物体反馈与音乐呼吸；可完全不用金色 |

导演在direction里用两句话说明选择。不要按题目标签机械选风格，不要求暗金片头，更不把所有主题换成骰子、金币或星盘。音乐、剧情与BPM独立决定。

## 一镜的美术卡（与认知分镜写在一起）

观众看什么→对象/尺度/支撑关系→主体明暗分组→相机为什么停或动→哪一处值得强调→声音哪里靠近/退出。

先试轮廓与灰阶，再定材质；先让物体站得住，再加精细反射。用一个方向明确的主光解释形状，补光只恢复必要信息。前景不等于加一条虚焦树枝；没有空间任务就不用景深。

### 暗部要有内容

- 把背景、物体暗面、地面/接触影分成可辨层次，而非一起压成RGB零。用环境渐变、距离/遮挡与材质差异建立空间。
- 黑色物体靠倒角、边缘反射和局部漫反射交代形状。若只能靠外发光看见轮廓，应回到几何/灯位。
- 暖高光与冷青灰只做轻微分离。若主体每面一样亮，先减补光/环境强度；若暗面消失，先调整物体角度/主光方向，再少量补光。
- 反射与照明是两件事：金属需要能反射的环境；只放一盏方向光会像涂黄漆。环境可以有宽暖柔光箱、窄冷反光板，不把画出的高光贴在物体屏幕位置。

### 材质不是滤镜

- 大形→倒角→粗糙度/金属度→细微纹理。没有倒角的盒子再加噪声仍像默认方块。
- 香槟/古铜是候选，不是所有实物的材质。石、纸、木、布、陶瓷应保留自己的反射性格。
- 纹理随对象UV运动，固定seed，一次初始化；不要每帧分配材质/PMREM。微纹理太粗会像锈蚀，太强bump会把仪器变成砂纸。
- 接触影必须与实际支撑一致。检查落放前/接触/后一帧、底部间隙和阴影，不能用固定椭圆阴影冒充复杂遮挡。

## 中文文字：给观看留位置

公共角色保留1080p旧起点：宋体标题76、概念86，黑体字幕64、标注42，等宽读数74，出处25；这不是手机合格标准。42px缩到320宽只有7px em，不能承担必要实验标签。[手机设计](mobile.md)先减信息密度、重构标注，再按角色/字数/字重/实际缩图选择尺寸；出处小字不承担关键知识，不统一按倍率扩大所有文字。

标题、主字幕、读数不同时争最大字号。暖白负责解释，金色只负责关键关系；错误/冲突才用克制朱红，冷青灰只作观察辅助。白天场景要改文字深浅，不能硬贴暖白金字导致看不清。

`type`复用Frame.text/measure的真实字宽，超宽报错，不悄悄缩字。超宽先改写/分两行/重新构图，不把字幕挤进角落。返回的是文字advance与保守高度，不是像素遮挡或审美评分。用390px宽图实际读主字幕和读数；标尺/出处必要时全屏看，不让关键解释依赖小字。

复用engine/index.html的字体声明。字体文件在磁盘不代表页面使用它；FontFaceSet.check对未注册的回退字体也可能返回true。type会检查指定VK字体确已注册且加载，否则明确失败，避免宋体/等宽角色静默变成系统回退字体。

## 可直接组合的实现

Canvas文字不需要Three：

```js
import {type,INK} from '/engine/vk-art.mjs';
type(fr,'同样的力，换个位置会怎样？',960,973,
  {role:'caption',align:'c',maxWidth:1660});
// 明场可覆盖color；不是全局换主题。
type(fr,'观察',112,144,{role:'title',color:INK.black});
```

真实空间需要时才加载：

```js
import {cinematicStudio,brushedMetal,beveledBlock} from '/engine/vk-cinematic.mjs';
const S=cinematicStudio({position:[1.2,1.2,3.1],target:[.45,.46,0],
  focus:[.3,.55,0],keyPower:3,fillPower:.28,environmentPower:.38});
const metal=brushedMetal({color:'#b6a381',roughness:.46,seed:16});
const rail=beveledBlock([1.05,.055,.105],metal,{bevel:.007});
S.scene.add(rail);
// 初始化一次。draw里按t设姿态、M.camera，再S.render。
// 结束预览/工程销毁时S.dispose()，材质纹理随材质释放。
```

这是灯光、几何与表面工具，没有预装道具、相机轨迹、配乐或故事。按主体尺度改focus、光位/强度、shadow.camera范围与曝光。原studio默认完全保留，额外支持exposure、environment绘制函数和返回fill；不用此方向的旧作品不加载它。

拉丝使用Three MeshPhysicalMaterial的各向异性、粗糙度/微高度纹理；倒角由Three ExtrudeGeometry生成真实法线。阴影是方向光PCF滤波，**不是面积光物理阴影/路径追踪/SSAO/真实景深**。不因模块名带cinematic就宣称画面达标。

## 镜头与声音一起呼吸

对象应该有静止状态、接触与落定，不能一直漂浮。相机为观察位置、尺度或机制改变而移动；读数揭晓时先落定。接触/形变用同一score事件，物理时间与镜头缓动分开。投影标注前M.camera会更新世界矩阵，避免标注落后于当前机位。

音乐从轻钢琴、拨弦、木琴、弦乐或其他合适语言选择，不因暗金就加低频轰鸣。高潮可通过和声/配器/密度或静默打开；不是把master推大。只给有触感意义的动作配音效。

先在短段合成真实分轨，检查音乐与动作的相对平衡，再作最终AAC同步/峰值检查。响度目标可能因峰值保护达不到，必须照实记录。没有听音能力就交分轨和完整混音供审查，不写“舒适听审通过”。更换素材须核对具体来源与许可，不能复制参考片音乐。

## 从实际错误返工

| 看到的问题 | 先改哪里 | 本轮可检查的例子 |
|---|---|---|
| 器具像默认方块、太远 | 形状倒角、支撑与取景，而非金色/辉光 | torque首版到后版 |
| 暗金变成灰雾或全黄 | 主光/补光/环境比例与表面响应 | 同几何同配色旧/新灯光对照 |
| 相机停后标注仍跳 | 实现层：当前世界矩阵，不改缓动掩盖 | 实测4–5px投影偏移，乱序seek回归 |
| 物体挤到字幕、箭头贴顶 | 改取景目标和标注位置，再看手机图 | 第二版到最终版 |
| 音乐比触感音弱很多 | 分轨增益与编配，不直接抬master | 新镜头先读采样幅度/混音，旧镜像原片不改 |

# 视觉设计配方：从目的到可检查的实现

一次只用与镜头任务有关的一两种。参数是 1080p 起点，不是全片必须遵守的装饰清单。

按题材评估[曜石鎏金艺术指导](art-direction.md)；可选灯光/反射、拉丝PBR、真实倒角与实测文字角色在公开模块，不预装影片道具或固定相机动作。原Canvas/B/C流程无需改用3D。

复杂实体不必每次手写投影与材质算法；先读[复杂场景制作](complex-scenes.md)，按部件和姿态约束复用成熟几何/深度/受光。六秒机构镜头提供可执行例子，仍以实际画面判断是否值得用3D。

| 能力 / 目的 | 适用情境 | 实现与关键参数 | 常见失败 → 改进 |
|---|---|---|---|
| 实体与接触 | 需要读懂谁支撑谁、谁碰到谁 | 先轮廓和遮挡，再漫反射大明暗，最后小高光；单一左上光源；接触影窄而深，离地后变宽变淡；实体进 `look.under` | 大辉光抹平表面 → 关闭 bloom，先看灰阶轮廓；不要把渐变球当所有材质 |
| 有目的的构图 | 多信息竞争 | 先画主体包围盒与字幕安全区；主体/证据/标签约 3 个层次，标题 80–140、正文 36–48、标注 24–32；空间留给动作方向 | 网页卡片感 → 去掉无关边框和按钮式圆角；让标签跟随对象关系，而非套网格 |
| 实物转图表 | 从现象走向规律 | 保留对象颜色和一条路径；摄影机先落定，再显轴/单位；图线用同一物理函数采样 | 只是溶解两张不相关图 → 明确哪个坐标对应刚才哪个物理量 |
| 景深与视差 | 需要感知距离 | 前/中/后分层；前景运动更大，远景更慢；焦点留给解释主体；模糊仅放非关键信息 | 全景发糊 / 假 3D → 回到遮挡、比例和接触；Canvas 不必模拟所有光学 |
| 文字成为动作 | 排列、删减、歧义、数字比较 | `fr.layout/chars/measure`；保留关键字位置，改变旁边的关系；数字用等宽字体 | 所有字都飞入 → 让字的位置变化本身代表逻辑，否则原地显现 |
| 自然运动与重量 | 物体接近、接触、离开 | 开始前短准备，快速主动作，短余动，读数停留；用位置-时间曲线检查速度 | 给真实仿真套 ease → 物理时间线保持真实；缓动只用于摄影机或注释 |
| 连续性转场 | 同一对象跨镜 | 在交接 t 保存同物位置、切线方向、尺寸；先留一个视觉锚点，再改变尺度 | 中间态混乱 → 检查 25/50/75% 帧；改变相机目标或用明确剪切 |
| 少元素的张力 | 观察、猜测、结论 | 一条路径、一个变化、一段等待；用负空间和声音停顿制造期待 | 安静等于空白 → 给观众一个可回答的问题；若没有，删镜头 |

## 画实体的最小层次

看 `examples/fold_C/film.js` 的 `bgCell/heroCell`：侧壁、表面、凹窝、局部高光分开画，且不参加辉光。
先用同一静帧关掉高光，检查物体仍可识别；再关掉纹理，检查空间仍成立。两者都靠装饰才成立，应重画轮廓和明暗。
粗糙材质高光宽弱、镜面高光窄强；程序纹理必须固定种子并随物体坐标移动，避免表面“游泳”。
保持光源固定，让物体转动改变受光；不要每一面都同样亮。Canvas 足够做局部投影和柔影；真实折射、多物体复杂遮挡才评估 WebGL。

## 相机与曲线

跨尺度用 `exp(lerp(log(s0), log(s1), k))`，按屏幕锚点检查焦点路径（fold_C 的 `camAt` 已有实现）。
相机平滑曲线不等于物体运动曲线。`VKit.track` 是 Catmull–Rom，可能越过关键值：镜头边界/比例不能直接假定不会超调。
`fr.poly` 的 k 按点序推进，不是按弧长；不均匀点列先做累计距离重采样，否则笔尖忽快忽慢。
复杂模拟预计算，渲染时按 t 查表；不逐帧积分。运动模糊不是救急办法：先让 30fps 中的关键动作保持可读，需多采样时先在 clip 上量性能。

## 实际教材

原版：fold_C 教尺度与因果；pigeon_B 教同一计时器跨景别；info_C 教文字本身成为实验（其视听设计不可直接发布）。
新增原创样片与同刻返工图见 [实验目录](../docs/experiments/director-2026-10/README.md)。
每种方法应读“意图→代码→参数→失败图→修订图”这一组，而非把画面当通用皮肤。

### 原创样片的三种可迁移机制

1. **实体 → 可测的实验。** `examples/descent_studio/film.js` 中轨面、侧壁、支杆和底座在同一投影下绘制，球体局部高光与窄接触影交代承托；颜色只负责区分两条路径。看 [10.5秒实图](../evidence/descent_studio/final/s_0010.50.jpg)。适合因果装置，参数先调实体比例、视角和接触位置，再调高光；不适合靠金属外观包装所有概念。
2. **运动 → 可读的定格证据。** 独立 `physics.js` 用绝对物理时间计算位置，摄影机另行缓动；17秒将同一物理时刻明确冻结，速度向量与数字给观众比较任务。初版镜头放得过大，箭头穿过字幕：[失败图](../evidence/descent_studio/v1/s_0017.00.png) → [修订图](../evidence/descent_studio/final/s_0017.00.png)。真正有效的参数是取景尺度1810→1450和标注位置，不是辉光强度。
3. **实物 → 几何定义。** 22–28秒保留铜色路径，转换为圆周点描出的摆线，并明确标注“几何生成示意”；此时运动表示几何构造，不能沿用赛跑计时。看 [24.5秒实图](../evidence/descent_studio/final/s_0024.50.jpg)。辅助圆接近名称区时先退出，避免解释工具盖住结论。适合一个对象有两种模型的叙事，不能用一次比赛冒充最速性的数学证明。

完整动作见 [36秒影片](https://raw.githubusercontent.com/Xuanyi-king/vibe-knowledge-film/8c93e14809b839586ab4652cf1e89b2a03876717/evidence/descent_studio/final.mp4) 与 [比赛 Motion Strip](../evidence/descent_studio/final/motion_8.8-13.2.jpg)。这些参数用于解释这次返工，不是新主题必须复用的布局。

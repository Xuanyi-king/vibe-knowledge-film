# 文案：一份给人"读"的字幕稿

> 下文的句数、字数、章节和片名结构来自历史 B/C 样本，是参考范围，不是所有主题的配额。
> 完整原创作品可按知识问题重排结构、把命名并入场景；不默认交付短样片。具体阅读时间以真实字体、画面负担和实际预览决定。

这类片子没有旁白，文案就是字幕。它不是口播稿删掉语气词，而是另一种文体：每句话都要承担明确的理解任务，可以配动作、定格证据或安静观察，
而且短到观众一眼读完还有余力看画面。下面的规律都来自四条参考片的完整字幕（见 `analysis.md`）。

## 先把研究变成剧情

先写两个自然句：“观众可能把……理解为……”和“离开时，能根据……解释……”。两句之间缺的那一步，才是片子的任务。
从真实实验、反直觉例子、推理或生活经验中选事件，让观众有机会先猜、再观察；研究者和年份只在这个问题需要他们时出现。

给核心主张各留四格：**证据做了什么／对照是什么／结果支持到哪里／哪部分只是解释或类比**。个人体验不能代替群体研究，相关不能直接叫因果；不要只读标题摘要就补造分组与数值。
原论文难读时先缩小论点，保留访问范围与未知。没有可用数值就比较条件和定性结果，不让虚构柱高、频率或动画计数冒充原始数据。

完整故事可走实验重演、悬疑、个人体验、尺度探索、思想实验等不同路径。先问每段解决前段什么疑问；不按固定三段/六段配额，也不因为有年份就写成历史目录。
结尾回到生活时，只交还研究允许的新视角：发现念头重现≠证明意愿；镜像熟悉≠客观颜值。若提出行动建议，另核相应干预证据，不能用情绪温暖越过证据。

[两题候选与参考导演方法](story-cases.md)；分镜与实现契约见[directing](directing.md)。

## 一、量

先写可独立阅读的完整字幕稿，再与分镜逐句对应。每句应能回答“谁/什么东西，发生了什么”；提问与结论可以没有新动作，但要承接刚才看到的事。少写“能力、判断、反馈、验证”这样的名词串，改成观众此刻看得见或做得出的动作。必要术语在例子之后命名，不一上来开概念课。

深沉靠准确、节制与留白，不靠晦涩。诗意句子放在过程已经被看懂之后；如果删掉它就不影响解释或情绪，便删掉。结尾应改变观众对开头那件事的理解，不追加无法从前文得到的鸡汤。

先独立读稿检查转折、指代、口气，再带着画面读一遍；避免主字幕、图内标签和出处重复说同一句话。默认中文衬线主字幕，不为“高级感”强加逐句英文或常驻口号。

| | 每分钟句数 | 每句字数（均 / 最长） | 每句停留 | 全片 |
|---|---|---|---|---|
| B 寓言 | 15 | 13 / 18 | 约 3.5s | 185s ≈ 47 句 ≈ 616 字 |
| C 夜曲 | 8–10 | 15–21 / 31 | 5–6s | 300s ≈ 37 句 ≈ 793 字；334s ≈ 53 句 ≈ 771 字 |

- 原样本常见单行范围：A ≤ 21 字，B ≤ 18 字，C 中文 ≤ 28 字（C 下面还有一行英文）。以真实字体测量为准；放不下先改句、换行或调整信息，不机械增加动作。
- 原样本有 26–42% 的时间**没有字幕**：片名、转场，以及让画面自己演的段落（模拟在跑、计数器在跳）。按理解任务留观察时间，不凑固定比例。
- B 如果卡现成配乐：一句 ≈ 两个小节（112 BPM 时是 4.3 秒），一站 = 小节的整数倍。

## 二、骨架

```
钩子（6–24s）      先演一个小东西，末尾抛一个问题或一句对"你"说的话
片名（4–14s）      2–5 个字的片名 + 一句人话的副题
主体（70–80%）     4–12 站，每站一个画面装置
转向"你"           把全片的概念落到此刻的观众身上
回扣 + 末句        回到钩子的画面；最后一句是片名的回声
片尾（3–5s）       片名 + 文献线索
```

以下是历史参考片的三种排法，不是通用配额或强制结构。思想实验、数学推演、微观探索等可另定叙事；不要为了套结构牺牲推理。

**A 编年体**（一门学问的来历）。每站 = `年份 · 地点 · 人物` + 一个问题 + 一个做法 + 一个带数字的结果，2–3 句话，4–17 秒。
全片要有一条**悬着的线**把各站串起来：luck 在 1494 年抛出"赌注怎么分"，给了一个错答案（5 : 2），
"这道题，一悬就是 160 年"，隔了五站才回来解掉（15 : 1）。没有这条线，编年体就是流水账。
站与站的关系是递进：问题 → 第一次去数 → 发现要算顺序 → 算未来而不是过去 → 从赌桌走到城市 → 大数 → 曲线 → 公理。

**B 论证链**（该历史片的一个机制为什么管住了我们）。该片采用的顺序：
现象（一个动物实验，讲成故事）→ 规则（一句话，印成卡片）→ 再两例（说明不是个例）→ 权威锚点 + 给它命名 →
一个意外又好笑的例子 → **转到人**（两个你每天碰到的东西）→ 一张图把所有例子装进去 → 最狠的一例 → 落到你身上 →
三步解法（每步是一个动作）→ 回到开场的动物 → 规则卡。
该片“转到人”在40–45%处、解法约10%；新主题按理解任务取舍，不硬塞转到人的段落。

**C 侧面体**（一个抽象概念）。双钩子（一个容易的例子紧跟一个"坏掉"的例子）→ 片名 → 五章左右，
每章名只有一个字（猜 / 惊 / 余 / 噪 / 义；画 / 数 / 机 / 生 / 我），每章 = 一个能当场玩的小实验 + 一个"年份 · 人名"锚点 + 一句定义。
章的顺序是从手边的游戏走到人：先让观众玩，再给定义，再给反面，再给边界，最后落到"你"。
各章讲的最好是同一个结构的不同化身，这样图形能复用，结尾能把五章压成五个图标。

## 三、句式

下面每一种都在参考片里反复出现。它们是可选写法；按题材写出准确、有目的的句子，不必从中选模板。

1. **两半句，后半句翻过来。** 前半句给直觉，后半句给事实，中间用分号或换行。
   - 摸一次，全凭运气；/ 摸上两万五千次，比例就会逼近真相。
   - 一个人的生死，谁也无法预料；/ 可一整座城的数字，却稳定得惊人。
   - 同样多的比特，可以是一首诗，也可以是一团乱码。
2. **破折号后面才是答案。** 术语和数字放在破折号之后，画面在破折号那一刻揭晓。
   - 这就是——大数定律。
   - 16 种未来，乙只赢 1 种——应分 15 : 1。
   - 把针随手撒在地板上，数一数压线的有几根—— / 竟然能算出 π。
3. **问句。** 观众需要先猜测时使用，后续画面给可见证据；不按句数配额插入。
   - 运气，能被计算吗？／真的公平吗？／最少要问几次？／烽火为什么值得点？因为敌人很少来。
4. **一句话写一个人。** 不写生平，只写一个让他像个人的细节。
   - 嗜赌的医生卡尔达诺，第一次认真地"数"运气。
   - 输急了的他，把问题交给了帕斯卡。
   - 他们清理了天线里的鸽子粪，噪声还在。／发明者后来说，他很内疚
5. **"不是……是……"只留给论点。** 全片一到三句，通常是末句或规则卡。
   - 它不笨，只是在照一条规则做
   - 冗余不是浪费，它是意义穿过噪声时的铠甲。
   - 假蛋赢，不是因为更好，而是因为更大。／怪圈不是故障，是世界回头看自己。
6. **直接对"你"说。** 钩子末尾一句，结尾一到两句。
   - 你的手机里，也有一颗／你一定猜到了下一个字。／此刻，是谁在读这句话？／这一次，由你来填。
7. **需要比较的数字要可核对。** 160年、25:27等示例来自历史参考。给出单位、计算和条件；查不到就保留定性或换证据，不能为了“具体”编造精度。
8. **需要原话时才引用。** 核对原句、译文和出处；引文可以成为画面主体，其他字幕停下，不按数量插入。
9. **末句可以呼应片名，也可以直接说出所得。** 先让观众看懂过程；回环仍不够清楚时，用“所以……”点明前文支持的认识或具体方法，留足阅读时间，不必套诗意句式。
   - 《运气的形状》→ 但运气，从此有了形状。
   - 《信息论 · 惊奇之学》→ 惊奇，是世界正在告诉你新东西的声音。
   - 《自指 · 我是个怪圈》→ 怪圈不是故障，是世界回头看自己。

删去寒暄、空泛预告、形容词堆叠和“众所周知”等套话。允许直接归纳刚才看到的推理和观众可用的方法；清楚优先于含蓄，不把“所以”本身当成禁词。句子优先写具体的人和东西做了什么。

## 四、一个比喻用到底

stim 全片只有一个比喻："假蛋"。它在第 2 句出现，之后奶茶是假蛋、短视频是假蛋、杜鹃是"最狠的假蛋"，
解法是"把假蛋挪出窝""把自己的蛋，放回窝里"，规则卡写"假蛋赢，不是因为更好，而是因为更大"。
观众不需要记住"超常刺激"这个术语也能复述整条片。

写稿时可先定这个词或关系：它可以是可见物、数学关系、空间结构或有边界的比喻，后面按需要回场，不要求每段套同一句式。
luck 的"形状"、info 的"惊奇 / 猜不到"、loop 的"怪圈 / 停不下来"是同样的用法。

## 五、事实

- 每个实质知识主张都要有可核对的锚：来源、推导或计算；不为凑锚而加无关年份、人名。站与站之间的因果（谁写信给谁、谁解了谁的题）也要查。
- 屏上给出处：原著的原文题名 + 中文译名；论文写"作者 等, 年份"；示意图标"示意"；假说标"一种假说"；传闻写"据说"。
- 决定含义的单位、比较对象、分母和适用条件要在主字幕或手机可读的主要图注交代，不能藏进小字。例如“第12百分位”要让人明白超过约12%的人，并非答对12%。辅助出处可放小字，关键条件仍需用人话讲清。
- 片尾一屏"文献线索 / 参考文献"，三到四行小字。
- 拿不准的事实，宁可换一个拿得准的例子。

## 六、标题和发布文案

- **片名** 2–5 个字，是概念本身或一个意象：运气的形状／超常刺激／信息论／自指。
- **副题** 一句人话，说清看完能得到什么：人类如何把偶然写进数学／为什么奶茶戒不掉，短视频停不下来／惊奇之学／我是个怪圈。
- **外文行** 拉丁文或英文大写小字，纯粹是气质：DE FORMA FORTUNAE／SUPERNORMAL STIMULI／INFORMATION THEORY · THE ART OF SURPRISE。
- **发布标题** 格式是"Vibe知识大赏 | 《片名》"，后面跟话题标签。
- **发布正文**（两条参考片这么写）：把片子前 30 秒的字幕连成一段话，从钩子讲到第一个结论为止，不剧透后半。

## 七、实际交付字幕稿与分镜

完整制作必须留下全片字幕原句与时间，可与逐镜动作合在`storyboard.md`。表格不是硬格式，文案与分镜本身不能省；仅有章节名、概念大纲或JS数组不够。历史示例见`visual-grammar.md`，不把示例的字句搬进新片。

```
# 起-止(s)  字幕（{词}=金，{!词}=红）               站 / 章
0.2-3.3     骰子落下之前，谁也不知道答案。           钩子
3.5-6.5     运气，能被{计算}吗?                      钩子（放大）
—           （片名，无字幕 6.6–10）
10.3-13.0   掷骰子，曾经是在向神发问。               序 · 古希腊
…
```

本系列沿用暖白解释、金色关键关系、朱红冲突/错误的语义，不逐章节换色；B/C历史样本也按原色义保持。每句少量强调，不能整屏字都在抢重点。

## 八、中英字幕分别管理

分镜先写中文原句，再列对应英文译文；共用起止时刻，中文成立后再翻译，不能为了英文长度删掉数值、前提或不确定语气。默认中文主行、英文辅行，用户要求纯中文则关闭辅行；该选择不改变旧B/C样式。

现有`K.subs`的数据为`{a,b,zh,en}`，其中night样式绘制英文；flat/gilt不会因为填了en便自动双语。自绘暗金字幕可以按同一数据分别排两行，不能只填英文而未检查实际画面。中文与英文的字阶、对比、断行和安全区分开测量，在390/320px实际图上核对；小字号英文不能承载中文没有的重要信息。

交付`subtitles/zh.srt`及启用时的`subtitles/en.srt`（UTF-8），由同一份字幕时间表导出，保留可修改的原稿。不能拿英文片名或文献标题冒充全片英文字幕。

# 分阶段执行提示

以下是Agent内部子任务包，不是要求用户逐轮发送指令。只加载上一阶段结论、当前镜头和相关参考页；完成当前任务后自动取下一镜头，持续到完整成片和验收。完整历史逆向 brief 已移到 [historical-prompts.md](historical-prompts.md)，不默认加载，不复制题材或视觉素材。

1. **理解**：从生活疑问写“观众原来相信什么／看完会怎样解释”。读原始方法、对照、结果、解释与限制，把事实和理论分开写入facts.md；不知道的留待核，不先画答案。
2. **构思**：在已定暗金外观内，为概念找外行认得的形象与动作。只有表达不确定才比较不同机制，不重新挑颜色和风格。写可见证据、观看顺序、误导边界；需要展开时读 directing.md。
3. **字幕与分镜**：先写全片实际字幕原句与时间，交到storyboard.md；每镜接着写对象、可见的中间原因、结果、观众懂什么、机位与声音，不能只有章节提纲。先预测/观察，再命名；体验、实验重演与类比明确区分。提问与结论可不配新动画。
4. **关键画面**：只实现最难镜头，截图。读 craft.md 对应配方。实物先形体和遮挡，再材质；字号用真实字体量。
5. **动作**：依据镜头契约实现确定性动画；物理时间不套缓动。做 Motion Strip 与局部视频，检查接触和中间态。
6. **返工**：先问剧情是否让观众亲眼理解答案。若删掉研究仍像成立，就是隐喻代替了证据；若删掉镜头仍不损理解/节奏，就是冗余。再给真实截图时间点、根因和最小修改，重截同刻画面记录结果。
7. **扩展与合片**：关键镜头可用后完成全片。先以指定Music为听觉基准，少量拟音加入后若更吵就减轻或删除，不按每个动作duck音乐。Standard完成全片编码、当前版本事件和分轨等技术检查，Release生成手机证据；另做画面/文案/听感审查，区分真实观看、抽样与未验收。

## 轻量模型的内部单镜头执行包

```text
本内部子任务实现镜头 S03，保持 direction.md 的颜色、光源和字阶。
输入：storyboard.md 的 S02 落点、S03 契约、S04 起点；facts.md 对应公式；engine.md 的 Frame API。
输出：S03 函数、一个静帧和一个 3 秒 clip，以及已定/未知/下一步。
先说明动作如何证明这个概念，再实现。静帧能看清不代表动画已通过。
完成后由同一Agent自动继续下一镜头；这个包不改变最终交付整部MP4的任务。
```

## 返工指令的格式

“在 12.4s 的证据图里，标签与轨道重叠，落点看不清。先改构图：标签移到对象外并用细引线连接；
不要改运动或颜色。重截 12.4s 和相邻动作，确认不遮字幕。”

如果证据显示概念没有讲清，返回候选方案；不要不断增加辉光或粒子。
